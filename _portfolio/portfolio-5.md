An implementation of the Inception Network in Python using PyTorch's basic `nn` module. The notebook features training of the network on the MiniPlaces dataset, which is a subset of the Places dataset which features 100 categories for image classification. This project was completed as part of the technical assesment for UCLA's DataRes club.
